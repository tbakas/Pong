# Pong
A reinforcement learning based project involving training a neural network to play pong. It uses the PPO algorithm and trains the model to predict where the ball will end up instead of simply tracking it continously. To do this, I created an algorithm for determining where the ball will be when a player or AI is able to hit it and rewarded the AI for moving towards it. And this is more of an informal project that I worked on purely out of interest. I trained the model using the pong_reinforcement.py file, and then I modified the code to make a game where you can play against it in pong.py with menus and pausing. You'd just have to rename the pth file to best_model.pth.
